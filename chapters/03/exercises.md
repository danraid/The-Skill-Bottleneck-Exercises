# Chapter 03: Cognitive and Contextual Bottlenecks

## Practical exercises

### E01

Conceptual: Explain the difference between context window saturation and semantic competition as sources of bottlenecks in agentic AI.

### E02

Practical: Modify the Python lab to simulate the lost-in-the-middle effect by placing the correct tool’s metadata in the middle of the prompt and measuring selection accuracy.

### E03

Critical Analysis: Discuss how trust-aware tool selection frameworks can mitigate reliability bottlenecks, and identify potential trade-offs.

### E04

Research: Summarise the main findings of regarding evidence scope, dispersion, and reasoning depth, and propose an experiment to test these properties in a new domain.

### E05

Security: Describe a prompt injection attack on tool selection and outline a basic defence mechanism. ---
