## How to study

1. Read the matching textbook chapter.
2. Attempt its exercises before opening the [worked answer notes](chapters/01/answers.md) for comparison.
3. Run the reference implementation and test suite in its linked lab folder.
4. Distinguish educational deterministic fixtures from true comparative LLM evidence.
