# Chapter 20: Adaptive Agent Systems and Open Research Problems

## Exercises

### E01

Conceptual: Explain the difference between skill evolution and skill composition in agentic AI systems. Why is skill consolidation important?

### E02

Practical: Extend the Python lab to include a third agent (e.g., a Monitor) that observes Planner and Executor. How does this affect fault detection and traceability?

### E03

Analysis: Given a trace where an agent completes all steps but the outcome is incorrect, discuss which observability layers are needed to diagnose the failure.

### E04

Critical Thinking: Discuss the trade-offs between high-fidelity observability and system performance in large-scale agent deployments. Propose strategies for balancing these concerns.

### E05

Research: Propose a metric for evaluating the generalisability of a skill library across multiple domains. How would you validate its effectiveness? ---
