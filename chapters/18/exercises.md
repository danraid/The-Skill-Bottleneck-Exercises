# Chapter 18: Reference Architecture – A Skill-Native Agent Platform

## Exercises

### E01

Skill Evolution: Extend the platform to support skill versioning and automatic fallback to previous versions on failure.

### E02

Observability: Implement a trace viewer that aggregates skill invocation logs and highlights failure points.

### E03

Security: Add a permission system to restrict which agents can invoke which skills.

### E04

Composite Skills: Implement a composite skill that chains two or more atomic skills.

### E05

Benchmarking: Design an experiment to compare the reliability of direct invocation vs. plan-and-execute orchestration. ---

## Review questions

### Q01

What are the key differences between traditional agent architectures and skill-native agentic platforms?

### Q02

How does skill orchestration improve agent flexibility and reliability?

### Q03

What are the main observability challenges in skill-native agentic systems, and how can they be addressed?

### Q04

Describe the role of security analysis frameworks such as ClawFuzz in skill supply chain management.

### Q05

Explain how operational reliability metrics extend beyond correctness in evaluating agentic systems. ---
