# The Skill Bottleneck — Companion Exercises

**Engineering Scalable AI Agents with Skills, Subagents, Playbooks, and MCP**  
**Author:** Daniel Raaid

This repository accompanies the printed textbook [The Skill Bottleneck](https://github.com/danraid/The-Skill-Bottleneck). It contains chapter-aligned exercises, model answer guidance, and runnable Python lab implementations with tests.

The learning materials use deterministic educational prototypes. They do **not** demonstrate measured LLM performance or verify production-grade security.
