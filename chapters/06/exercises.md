# Chapter 06: Skill Retrieval and Progressive Disclosure

## Exercises

### E01

Skill Library Expansion: Add five new skills to your library, each with a description and a body. Test retrieval accuracy for different queries.

### E02

Distractor Skills: Introduce distractor skills with misleading descriptions. Observe how retrieval accuracy changes.

### E03

Body-aware Retrieval: Modify the retrieval function to use both description and body content. Compare retrieval accuracy and context usage.

### E04

Progressive Disclosure Depth: Implement a three-stage disclosure (description → summary → body). Measure if this improves or degrades retrieval accuracy.

### E05

Security Simulation: Add a skill with a potentially harmful command in its body. Discuss how progressive disclosure could help mitigate accidental execution. ---

## Review questions

### Q01

What is the main motivation for using progressive disclosure in agentic systems?

### Q02

How does skill retrieval differ from traditional information retrieval in LLM pipelines?

### Q03

What are the trade-offs between retrieval accuracy and context efficiency when hiding skill bodies?

### Q04

Why is a single level of progressive disclosure usually sufficient?

### Q05

How can skill organisation affect agent runtime behaviour and outcomes?

### Q06

What are the main security risks introduced by skill ecosystems, and how can progressive disclosure help mitigate them?

### Q07

How do benchmarks like SkillRet and SRA-Bench inform the design of retrieval-augmented agent systems? ---
